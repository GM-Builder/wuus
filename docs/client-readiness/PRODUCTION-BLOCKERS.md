# Gate produksi dan tindakan akun

Pemeriksaan read-only 7–8 Oktober 2026; owner mengonfirmasi registrar Rumahweb, apex hidup dan sudah memiliki Zoho Mail gratis. Tidak mengganti DNS, mengubah Supabase produksi, membeli plan, atau mempublikasikan deployment.

| Gate | Bukti sekarang | Tindakan berikutnya |
| --- | --- | --- |
| Supabase aktif | Owner memilih SQL Editor manual; CLI login tidak diperlukan untuk alur ini. Host config lokal lama gagal DNS saat audit; project aktif belum dicocokkan | Owner buka project aktif; ikuti `supabase/manual/README.md`, inspect/backup, apply terkoordinasi dengan release aman, verify. Cocokkan URL/key pada environment; bukan menyalin config lama tanpa pemeriksaan |
| RLS/Auth produksi | Migration 001/002/003 dan bundle satu transaksi manual lulus; column-level grants/outbox policies lama dicabut; data historis dipertahankan. Produksi belum verified | Owner inspect/apply/verify; review indirect routines/views, test REST roles/concurrency staging, buat/pilih Auth owner dan set server allowlist, lalu rilis terkoordinasi |
| Hosting/domain yang benar | Registrar/name servers Rumahweb confirmed; apex HTTPS 200. CLI BinaHub Hobby masih hanya menunjukkan webuntukusaha.vercel.app; account/project yang menjalankan apex belum dicocokkan | Gunakan DNS Rumahweb. Identifikasi project hosting apex sebelum mengubah env/deploy; domain yang hidup tidak membuktikan kode lokal terbaru sudah live |
| www/canonical live | Apex HTTPS 200. DNS www: NXDOMAIN. HTML live canonical masih `https://www.webuntukusaha.com`. Canonical apex dan 308 redirect siap/teruji lokal | Di akun yang benar, hubungkan www dengan nilai DNS yang diberikan provider, preserve mail records, arahkan www→apex, deploy versi aman; verifikasi path/query, HTTPS, sitemap dan canonical |
| Komersial | Akun tersambung Hobby; belum membuktikan plan akun pemilik domain | Pilih hosting komersial dan pembayar. Jangan beli plan tanpa dana. Kit klien statis punya pilihan host berbeda; website WUUS ber-API perlu runtime yang sesuai |
| Notifikasi owner | Owner menetapkan `admin@webuntukusaha.com` untuk notifikasi dan `hallo@webuntukusaha.com` untuk publik; Zoho Free sudah ada dan MX DNS mengarah Zoho. Recipient terisi lokal; outbox/adapter lulus lokal. Mailbox/alias, Resend key/domain dan actual inbox receipt belum verified | Zoho inbox + Resend Free sending subdomain. Ikuti EMAIL-SETUP.md; preserve mail records, isi fixed sender/recipient/server key pada hosting yang benar, uji actual inbox kedua alamat |
| Pembayaran | Owner meminta rekomendasi, belum memberikan rekening/provider. Rekomendasi: Wise client→bank IDR, alternatif PayPal Invoice; account/rute belum verified | Ikuti PAYMENTS.md: bank/payee private, actual country/currency quote, settlement/fees/hold jelas dan direct receipt verification. Tidak mengklaim owner punya IBAN/SEPA atau dana sudah masuk |
| Builder live | API pause lulus lokal; project hosting/payment provider builder belum teridentifikasi pada akun tersambung | Deploy containment di project yang benar, periksa invoice Mayar/top-up lama dan transaksi tertunda; jangan membuka kembali AI/payment endpoints |

Owner cukup memberi identitas akun/project/penyedia dan melakukan login lewat layanan terkait. **Jangan kirim password/token/service key di chat.** Server secrets dikonfigurasi di environment provider yang benar. Setelah akses tersedia, seluruh pekerjaan rilis mengikuti [runbook](RELEASE-RUNBOOK.md), termasuk backup sebelum perubahan database.

Dokumen dan simulasi selesai bukan bukti produksi siap menerima inquiry/DP. Tidak ada production gate yang diberi status DONE tanpa hasil live yang mendukungnya.
